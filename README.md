# Gold Trader Pro — Phone Dashboard

This is the **dashboard-only demo build** prepared for easy phone testing.

## What it does
- XAUUSD / XAUAUD tabs
- Demo signal creation with BUY/SELL, entry, SL and TP
- Local signal history
- Local demo trade records
- Risk/settings screen
- Mobile-first dark UI

## Important
This build does **not** connect to IC Markets, MT4/MT5, or place orders. It is intentionally safe for UI testing.

## GitHub Pages
Upload `index.html` to the root of a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

GitHub will provide a public/private Pages URL depending on your account/repository settings.

The MT4/MT5 EAs and backend are intentionally excluded from this phone-only prototype.
